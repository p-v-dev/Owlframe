# Owlframe

Editor desktop, open source e local-first para criar diagramas visuais de arquitetura de software e infraestrutura.

## Requisitos

- Node.js 22 ou superior
- npm 10 ou superior

## Instalacao

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Exportacao

Exporte a vista ativa como SVG ou PNG. O PNG oferece escalas de 1x, 2x e 3x, e ambos os formatos podem usar fundo transparente ou o fundo do tema.

## Verificacao

```bash
npm run check
npm run build
```
